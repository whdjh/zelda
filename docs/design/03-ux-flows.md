# 모바일 탐색과 경로 재구성

2026-11-09 사용자 결정. 전체 노선을 점과 연결선으로 탐색하고 사용자 진행에 맞춰 남은 연결과 배치를 재구성한다. [ADR-014](../decisions/001-architecture-decisions.md), [조건 조사](../research/06-route-network.md)를 함께 따른다.

## 노선 탐색

- /oot에 접속하면 소개 화면 없이 전체 노선과 진행도·설정을 바로 사용한다. 기존 /oot/route는 /oot로 이동한다. 기본 목적지는 엔딩이다.
- 상시 번호·카드는 사용하지 않는다. 점에 호버/키보드 포커스하면 이름, 터치로 450ms 길게 누르면 이름 미리보기, 한 번 탭하면 SEED Bottom Sheet 상세를 연다.
- 스크롤 중 손가락 이동·pointercancel은 길게 누르기를 취소한다. 길게 누른 뒤 놓을 때 상세가 함께 열리지 않는다. Escape로 이름을 닫는다.
- 전체 노선 / 남은 경로 / 목록 보기를 제공한다. 목록에서는 이름과 상태로 바로 선택할 수 있다.
- 완료한 역은 별도 펼침 영역에서 취소할 수 있다. 다른 역을 자동 완료하지 않는다.
- 모든 필요한 연결을 계산하되 화면에서는 우회 연결로 이미 표현된 중복 선행선을 축약한다. 실선은 진행 조건, 점선은 장비 획득 경유다. 여러 입력은 AND 조건이며 서로 대체 가능한 길이라는 뜻이 아니다. 선 교차만으로 환승을 표시하지 않는다.
- 같은 분기의 역은 세로축을 유지하고 수직선·45도 대각선의 모서리만 둥글게 연결한다. 여러 줄을 건너뛰는 선은 중간에도 공간을 예약하며 SVG를 가로로 늘리지 않는다.
- 준비가 확인된 후보를 우선 안내한다. 시각적 길이와 이동 시간은 관계없으며 최단 시간 보장으로 소개하지 않는다.

## 역 상세

목표 → 완료/취소·여기로 경로 보기 → 연결 이유와 선행 구간 → 시대·준비물 → 선택적 장비 기록 → 상세 해법·퍼즐 도움 → 접힌 출처 정보.

완료는 조건 때문에 비활성화하지 않는다. 실제로 플레이한 사실을 사용자가 직접 기록한다. 장비와 시대는 별도 기록이며 자동 획득하지 않는다. 선택 목적지와 장비 변경 후 재구성 안내를 status로 알린다.

## 공개와 저장

기본 full은 전체 노선 접근을 허용한다. strict는 완료/추천 외 이름을 DOM에서 제외한다. 이전 default 설정은 full로 읽는다. 상세 해법과 힌트는 명시적 요청 전 DOM에 넣지 않는다.

진행·장비·시대·목적지·힌트는 localStorage에 저장하고 JSON 백업/복원을 제공한다. 손상 원문, 저장 차단, 다른 탭 충돌 보호를 유지한다. 로그인/서버 기록은 후속 준비 코드다.

한 화면의 설정과 노선은 페이지에서 한 번 생성한 useProgress 결과를 props로 공유한다. 스포일러 변경·백업 복원·완료 기록은 새로고침 없이 함께 반영한다. 역·퍼즐 고유 주소는 직접 진입용으로 유지한다.

## 검증

360/390px 페이지 가로 넘침, 점 터치 영역, 호버·길게 누르기·키보드, 시트 열기/닫기, 선택 목적지 복원, 장비 확인으로 경유 제거, 비선형 완료·취소, 해법 미노출을 확인한다. 실제 휴대폰 제스처·스크린리더 검수는 브라우저 자동 검사와 별도로 남긴다.
