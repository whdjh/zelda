## 출처 계보와 독립성

[OoT Guide 지도 안내](https://ootguide.com/ko/map/remake/?area=kokiri-forest&mode=walkthrough)는 절차·수집·이미지가 GameWith와 Nintendúo 자료를 정리한 것이라고 명시하고 자체 전수 플레이 검증을 주장하지 않는다. 따라서 C01과 G01/G02를 독립 출처 두 개로 세지 않는다. 번역/미러/정리 사이트를 찾으면 먼저 원출처와 계보를 기록한다.

G02/G04/G05는 각각 별도 편집처의 본문을 대조했다. 같은 사실의 일치와 실제 취재 독립성은 구분하며, 공통 오류 가능성은 직접 플레이로 확인한다. Y01은 계속 개별 영상 미검증이며 임의 영상·시점을 추가하지 않았다.

## 정보의 성격을 구분

초기 구현의 기술 자료와 이후 집필 자료를 구분한다. 이번 전 구간 집필에서는 GameWith의 장별 본문·보스 글과 Zelda Dungeon Wiki의 첫 던전·동굴·시간의 신전 본문, GamesRadar+ 시작 장비 글을 읽고 앱 데이터를 작성했다. 실제 사용한 URL과 데이터 ID는 [sources.ts](../../content/ocarina-of-time/sources.ts), 사용 범위·충돌·미검증은 [전 구간 집필 기록](05-oot-story-draft.md)에 기록한다. 직접 플레이 검증은 수행하지 않았다.

- **게임의 객관적 사실**(아이템 획득 조건, 진행 필수 이벤트)과 **우리의 추천**(이 길이 효율적)은 별개.
- 서로 독립적인 자료인지 확인. 하나의 원문을 복제한 페이지 두 개는 독립 근거 아님.
- N64/3DS와 Switch 2의 차이는 반드시 판본 표시.
- 출처의 조회 수/검색 순위로 최적 루트의 진실성을 판정하지 않는다.
- 개별 영상의 실제 내용/시점은 직접 열람한 후 `Y01-001` 같은 기록으로 추가.
