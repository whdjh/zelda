# PRD — 젤다 하이패스 v1.0

> 제품 범위/행동 기준 **확정**. 개별 게임 경로·상용명·트래픽 수치는 **검증 필요**.

## 현재 실행 순서

최신 사용자 결정은 **메인 `/` 하나와 핵심 기능만 유지**하는 것이다. 네비바·사이드바·별도 역/퍼즐/로그인 페이지·미래 기능 준비 코드는 제외한다. 먼저 엔딩까지 스토리·던전·보스·퍼즐의 누락 없는 목차와 자체 설명을 작성한다. 하이패스는 이를 짧은 목표/노선/힌트로 읽는 방식이다. 100% 수집의 세부 범위는 별도 확정한다.

## 1. 문제와 타깃

**주 사용자:** Nintendo Switch 2용 《시간의 오카리나》를 처음 또는 오랜만에 플레이하는 한국어 이용자 중, 프레임 단위 기술 없이 엔딩을 **안정적이고 빠르게** 보고 싶은 보통 조작 실력의 사람. TV/스위치 옆에 스마트폰을 두고 간단히 확인.

위키는 가능한 정보를 많이 나열하고 게임 내 보조 기능은 목표 추적을 돕는다. 이용자는 여전히 **'지금 무엇을 하고, 어떤 준비가 시간과 실패를 줄이는가'**, **'정답 없이 힌트만 얻을 수 있는가'**를 빠르게 해결해야 한다. 본 문제 진술은 검증할 가설이지 모든 이용자의 공통 경험으로 단정하지 않는다.

## 2. 약속

> **게임의 재미는 남기고, 헤매는 시간은 줄인다.**

- 최단 **지도 거리**보다, 이동/준비/문제 해결/전투/재도전 등을 포함하는 **예상 총 소요시간과 실패 위험**을 고려.
- 글리치·고난도 트릭을 기본 전제로 삼지 않는다.
- 공략은 '일반 사용자 추천 루트'로 소개. 전 구간에서 실측되지 않은 '세계 최단' 주장은 금지.

## 3. 출시 시 포함(P0)

| 기능 | 사용자 행동/수용 기준 |
| --- | --- |
| **메인 스토리 노선도** | 전체 역의 점과 분기·합류를 모바일에서 탐색하고 호버·길게 누르기·포커스로 이름, 탭으로 상세를 확인한다 |
| **역 요약** | 선택 시 SEED Bottom Sheet에서 최대 세 문장으로 다음 행동/필수 준비/목표 확인 |
| **단계별 퍼즐 힌트** | 단서 1 → 2 → 해법 3 순차 요청; '바로 정답' 선택 가능; 기본 자동 노출 금지 |
| **현재 진행 변경** | 역 완료/취소, 확인된 보유 조건 변경 → 선택 목적지까지 남은 연결·배치 재구성; 완료는 자유롭게 기록하고 준비 조건은 안내 |
| **스포일러 정책** | 기본은 전체 공개, 엄격 설정에서만 미래 역 이름을 가림. 전체 노선 공개와 해법 공개는 별도 |
| **진행도 유지** | 비로그인 localStorage·JSON 백업·저장 실패 고지. 선택 로그인과 서버 저장 연결은 공략 핵심 흐름 이후 |
| **한국어 검색 진입** | 메인 URL과 올바른 한국어 명칭, 검색 결과에서 정답 직접 누출 방지 |
| **검증 근거** | 공개 데이터는 출처/판본/검증 상태 내부 메타와 함께 관리. 사실 오류 신고 가능 |
| **모바일 기본 사용성** | 터치, 스크린리더, 작은 화면, 가로 회전 및 서체 확대 대응 |

P0의 범위는 **초반만 만든 실험 사이트**가 아니라 시오의 엔딩까지 이어지는 플레이 가능 흐름이다. 다만 게임 전체 콘텐츠는 조사/검증을 거쳐야 하며 검증 없이 '완성' 표시 금지.

## 4. 출시 시 제외

100% 수집품 공략, 야숨·왕눈 실제 루트, 필수 미디어 GIF/영상, 실시간 자동 동기화·자동 병합, 실시간 LLM 개인화, 사용자별 AI 레이아웃 재생성, 게임 진행 자동 감지, 외부 공략 재게시.

## 5. 후속 확장 방향

1. **100% 수집 모드**: 메인 하이패스와 분리된 별도 탐색 경험으로 출시. 스토리 진행 데이터와 연결 여부는 개발 시점 판단.
2. **서버 기록 확장**: 실제 필요가 확인되면 Next.js 서버 기능 + Supabase를 검토한다. 현재 준비 코드와 전용 의존성은 없다. 실시간 동기화·자동 병합·계정 삭제 UI는 별도 설계하고 개인정보/탈퇴 절차를 검토한다.
3. **AI 경로 개인화**: 유저 보유 아이템/선호를 근거로 경로 제안. 실제 경로 변경·레이아웃 업데이트는 검증된 게임 데이터/규칙으로 렌더링. AI가 좌표를 마음대로 그리는 것은 후속 별도 검증.
4. **야숨·왕눈**: 사용자 실제 플레이 경험을 기반으로 같은 철학 적용. 지금 세부 공략 설계는 하지 않는다.

## 6. 핵심 사용자 흐름

검색/직접 방문 → 소개 화면 없이 노선·진행도·설정이 있는 단일 메인 화면 → 자신의 진행 지점 설정 → 현재 역의 3문장 가이드 → 퍼즐은 필요한 단계만 힌트 → 완료 기록 → 규칙 기반 분기·합류 재구성 → 다음 플레이에 복원 → 엔딩.

## 7. 성공 검증 (숫자 임의 설정 금지)

- 유입: 한국어 검색 노출·클릭, 메인에서 구간/퍼즐 열람.
- 효용: 지금 할 일을 찾는 성공률/시간, 퍼즐 도움 만족도, 실제 진행 복귀 여부.
- 반복: 진행도 복원률, 7/28일 재방문, 활성 사용자(정의 고정) 및 **MAU**.
- 루트 정확성: 출처 재현성, 직접 플레이 실패 지점, 준비 경유가 재도전/전체 시간을 줄이는지 비교.

시장 규모·MAU 목표·검색량은 실측 전이다. 개별 게임의 수명이 MAU를 제한할 가능성을 분석한다.
