# 공략·유튜브 자료 조사 프로토콜

## 목적

2026-11-16 결정: 조사에서는 여러 사이트를 대조하고 앱의 참고 공략 링크는 GameWith 한 곳으로 통일한다. 실제 출처 메타는 보존한다. 웹 조사만으로 최단 기록을 증명했다고 표시하지 않는다. [시간 검토 결과](../research/07-route-speed-audit.md).

기존 사이트/영상의 내용을 '복붙'하는 게 아니라, 게임의 **사실·선행 조건·진행 선택지**를 추출하고 비교해 독자적인 한국어 안내를 제작한다.

## 출처 우선순위

1. **게임 직접 플레이 기록(리메이크)**: 실제 퍼즐·조건·스크린샷 원본의 검증 용도. 게시물의 이미지 사용은 별도 법적 검토.
2. **한국닌텐도 공식 정보**: 게임 명칭, 출시판, 공인된 메커니즘 및 서비스 범위.
3. **리메이크 전용 공략 사이트/영상**: 순서와 조작, 변경점 교차 확인.
4. **과거 N64/3DS 공략**: 배경과 후보 경로에만 활용, 현 리메이크 적용은 확인 필요.
5. **개인 경험·커뮤니티 의견**: 시간 절약/위험도에 대한 가설, 사실과 구분.

## 사용자 추천 채널

`https://www.youtube.com/@nintaku_chick`

이 채널은 사용자가 품질이 높다고 평가한 **조사 우선 후보**다. 현재 개별 영상 제목·실제 플레이 구간·설명은 외부 접근 문제로 검증하지 못했다. 확인한 적 없는 영상을 추천 근거로 인용하지 않는다.

영상 하나를 분석할 때 `docs/research/02-youtube-review-template.md`의 포맷을 사용한다. 타임스탬프는 동영상에서 직접 확인한 뒤만 기입한다. 공략과 무관한 흥미·트릭 영상은 구분한다.

## 조사 워크플로

1. 구간을 게임 안의 객관적 이벤트로 정의 (예: '첫 던전 진입 전' — 아직 구체 동선 확정 금지).
2. 해당 구간의 한국어 공식 명칭을 확인한다.
3. 외부 출처 2개 이상에서 같은 요구 조건을 확인한다 (다른 출처라도 같은 원문 재인용인지 살핀다).
4. 출처가 서로 다르면 별도의 '충돌 기록'을 만든다. 추측으로 봉합 금지.
5. 기본 동선과 후보 단축을 비교한다. 조작 난도, 시대·시간대·장비 조건을 기록한다.
6. 추천 여부는 `01-route-criteria.md`에 따라 결정.
7. 자체 문장으로 3줄 요약과 3단계 힌트를 작성.
8. 실제 Switch 2 리메이크 플레이에서 확인 후 `playtested` 승격.

## 인용·미디어 원칙

- 영상에서 얻은 사실은 URL과 **정확한 시점**을 기록한다.
- 영상 캡처/추출 GIF/WebP의 호스팅은 자동 허용되지 않는다. 외부 영상은 우선 링크만 제공.
- 게시물의 텍스트, 영상 구성, 썸네일, 지도를 실질적으로 재현하지 않는다.
- 3줄 안내와 그림은 자체적으로 작성한다. 허락받거나 독립 제작한 미디어만 사용.
- 자동 수집/스크래핑은 이용약관과 저작권, 로봇 정책 확인 전 시행하지 않는다.
