# 시각 디자인 기초 규칙 — 기존 디자인 시스템 우선

## 기본 선택

- **기본 UI:** SEED Design React. 독립 디자인 시스템 제작 금지.
- **스타일:** Tailwind CSS v4 + 공식 SEED 테마 연동, 필요한 고유 노선도만 CSS Modules.
- **토큰:** 색/폰트/간격/라운드/상태 색은 SEED의 scale·semantic 토큰 우선 사용. 프로젝트만의 Primitive→Semantic→Component 복제 금지. 세부 규칙은 [`05-seed-token-policy.md`](05-seed-token-policy.md).
- **분위기:** 판타지 게임 UI를 복제하는 대신 **모바일 내비게이션 + 숲/지도의 추상적 모티프**를 제한적으로 반영.

## 디자이너 기초 이론을 사용성으로 연결

| 원리 | 제품에서의 적용 |
| --- | --- |
| **시각적 위계** | 1순위 현재 목표 → 2순위 지금 할 행동 → 3순위 필수 준비/부연. 크기만이 아니라 대비·공간으로 구분 |
| **근접성** | 역 이름·완료·행동을 한 그룹에, 선택 수집 요소는 따로 |
| **정렬** | 노선 축/역/시트 라벨의 시작선을 일치시켜 한눈에 훑기 |
| **반복과 일관성** | 같은 상태에 같은 형태/아이콘/색/어휘를 써 학습 비용 최소화 |
| **대비** | 배경/텍스트와 현재/잠금의 구분, 대비 자동 검사. 색만으로 의미 전달 금지 |
| **여백** | 불필요한 콘텐츠를 줄이고 한 화면에서 다음 행동을 곧바로 찾게 구성 |
| **정보 밀도** | 홈에는 현재/다음 역과 한두 행동, 세부 정보는 시트/명시적 힌트에서 공개 |

## 색·테마

- 다크 UI는 제품 콘셉트 후보로 유지한다. 초기 구현은 SEED light-only이며 다크 전환은 실제 대비와 모바일 검증 후 도입한다.
- 녹색 기반의 '현재/진행' 강조를 선호하되 `#16a34a` 등의 고정 HEX를 앱 전체에 하드코딩하거나 색 팔레트를 새로 만들지 않는다. SEED 의미 토큰을 검토해 적절한 역할을 찾고 **current와 success를 무조건 같은 의미로 취급하지 않는다**.
- SEED로 해결되지 않는 현재역/노선선 상태에만 alias 토큰 추가. 금색 장식은 사용성·대비가 입증될 때만 소량.
- 배경 이미지, 반짝임, 게임 로고/트라이포스 등 기존 IP 요소를 기본 UI로 가져오지 않는다.

## 타이포그래피

- SEED 기본 typography 토큰/서체 설정을 우선 채택. 한글 화면에서 가독성 문제가 실제로 확인되면 Pretendard 등 **라이선스 확인된 폰트**를 단일 시스템 서체로 정한다.
- 페이지/역/본문/설명/상태에 의미 있는 계층을 둔다. 새로운 크기마다 폰트 토큰을 만들지 않는다.
- 한국어 긴 제목, 200% 확대, 동적 줄바꿈에서 버그가 없는지 확인. 가독성을 해치는 장식용 팬 폰트는 금지.

## 간격·모서리·그림자·모션

- SEED 간격과 컴포넌트 크기를 우선 사용. '4/8/12/16/24' 간격 시스템을 **별도 정의하지 않는다**.
- 게임 고유 노선 연결선/역 크기는 필요한 경우 컴포넌트 범위에서만 CSS 변수로 정의.
- 부가 애니메이션은 장식이 아니라 현재 위치 이동/시트 열림/힌트 공개라는 목적에만 사용. `prefers-reduced-motion` 지원.
- 원문 레이아웃을 '픽셀 퍼펙트'하게 재현하는 것이 아니라 3초 내 현재 할 일 파악을 평가한다.

## 접근성·모바일

- 손가락 조작에서 핵심 터치 영역 44×44px 목표, 텍스트 대비 WCAG AA 기본 기준(일반 본문 4.5:1; 컨트롤 표시 3:1 등) 확인.
- 스포일러를 흐림 필터만으로 가리지 않는다. 글자는 DOM/스크린리더/검색 미리보기에서 실제 비노출.
- 360/390px, Safe Area, 확대·가로 회전, 키보드/스크린리더. 완료/현재/잠금은 텍스트와 아이콘을 동반.
