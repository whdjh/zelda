# 엔딩 경로 시간 검토와 참고 사이트 통일

조사일: 2026-11-16. 대상: `oot-switch2-2026`. 판정: **현재 경로의 최단시간은 입증되지 않았다.** 일반 조작·특수 우회 없는 엔딩이라는 기존 제품 기준으로 조사했다. 세계기록 도전용 루트와 동일하지 않다.

## 조사 범위와 결론

검색으로 후보를 찾고 아래 7개 사이트의 관련 본문·목차·조건 설명을 열람했다. 인터넷의 모든 사이트를 조사했다는 뜻이 아니다. 30역을 장별 참고 자료에 대응시키고 주요 진입 조건, 시대 전환, 선택 경유, 최종 진입 조건을 검토했다. 31문제의 모든 해법·모든 방·보스 최속 전투를 이번에 전수 재검증한 것은 아니다.

앱의 `selectRoute`는 준비된 후보를 **콘텐츠 배열 순서**로 선택한다. 이동 위치, 워프 습득 상태, 전투 시간, 실패 확률, 이동 비용이 입력에 없다. 따라서 조건에 맞는 경로를 보여주는 기능이며 시간 최적화의 증거가 될 수 없다. 자동 테스트 통과도 게임 클리어·최단시간 증거가 아니다.

현재 공개 자료만으로 기존 루트가 다른 모든 합법적 루트보다 빠르다고 결론 낼 수 없다. 반대로 동일 출발 상태·동일 실력·동일 판본으로 측정하지 않았으므로 다른 루트가 반드시 더 빠르다는 결론도 내리지 않는다. 모든 콘텐츠의 `proposed`를 유지한다.

## 비교할 후보와 미측정 항목

추가 본문 수정: [GameWith 혼의 신전](https://gamewith.jp/zelda-tokino-ocarina/563384)의 소년 구간은 금 간 **벽**에 폭탄쥐를 사용하는 것으로 안내한다. 기존 본문의 '바닥의 금'을 수정했다. 전체 퍼즐 전수 재검증으로 확대하지 않는다.

| 후보 | 기대하는 이점(가설) | 현재 판정 |
| --- | --- | --- |
| 기본 숲→불→얼음→물→우물→어둠→혼 | 장별 자료를 연속해서 따라가기 쉬움 | 현재 추천 목차. 가장 빠르다는 측정 없음 |
| 얼음/물을 먼저 진행 | 출발 위치·기보유 장비에 따라 재방문 감소 가능 | 일부 조건 연결 지원. 활 대체·전 구간 시간 미검증 |
| 혼을 어둠보다 먼저 진행 | 이동·시대 전환 순서 재배치 가능 | 경로 후보만 가능. 더 빠르다는 보장 없음 |
| 에포나·여러 병·추가 방어 준비 | 이동 또는 실패 손실 감소 가능 | 획득 비용과 총 이득을 재야 함. 필수화하지 않음 |
| ZSR의 특수 우회 | 일반 목차의 구간 생략 가능 | 기존 보통 실력/글리치 제외 기준 밖. 일반 추천에 편입하지 않음 |

검증 시 같은 게임 빌드·출발 저장·장비·목표·허용 기술·계측 시작/끝을 고정한다. 후보별 이동/준비/전투/실패 재시도를 포함한 전체 시간을 반복 기록하고 성공률과 중앙값을 비교한다. 유리한 결과가 나와도 '측정한 후보 중 빠름'으로만 보고한다. 현재 실측값·영상·런 기록은 없다.

## 참고 사이트 통일 방법

앱의 공략·힌트·조건·팁에서 여는 **참고 공략 링크는 GameWith 한 사이트**로 통일한다. `Verification.guideSourceId`는 같은 구간의 읽기 링크다. 해당 링크가 팁의 모든 문장이나 시간 우위를 증명한다는 뜻은 아니다.

`sourceIds`와 출처 등록부는 실제 집필/교차조사 이력으로 보존한다. 다른 사이트에서 얻은 사실을 GameWith의 사실로 바꿔 적지 않는다. 같은 GameWith의 두 페이지도 독립 출처 두 개로 세지 않는다. 검증 상태는 모두 초안이며, 출처 패널에 최단시간 미검증을 표시한다.
