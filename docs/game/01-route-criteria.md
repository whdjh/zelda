# 추천 루트 선정 원칙 (핵심 문서)

## 우리가 최적화하는 것

'지도상 최단 거리'나 '숙련자 최고 기록'이 아닌, **일반적인 조작 실력의 유저가 엔딩을 안정적으로 보는 데 드는 예상 총시간**.

관찰 기준: 경로 이동 + 상호작용/퍼즐 + 장비·소모품 준비 + 실패·재도전으로 소모한 시간.

### 관찰 모델 (개념식, 실측값 아님)

`T_total = T_travel + T_progress + T_preparation + E[T_retry]`

`E[T_retry]`는 실패 확률과 실패 시 잃는 시간을 반영할 수 있지만, 현재 측정치가 없으므로 **임의의 확률을 입력해 랭킹하지 않는다**.

## 일반 사용자 가정

- 글리치, 버그, 프레임 단위 입력, 비표준 조작, 세이브 편법 등을 전제로 하지 않음.
- 정상적인 게임 시스템·획득 가능한 아이템·보편적인 회피/전투 조작만 이용.
- 길 찾기/퍼즐에 시간이 걸릴 수 있음. 해결책을 바로 보여주지 않고 필요할 때 힌트를 공개.
- 재방문, 시간대/소년·청년 상태 변경 등 실제 선행 조건이 포함됨.

## 구간 분류

| 종류 | 노선도 표시 | 포함 규칙 |
| --- | --- | --- |
| **필수역** | 선명한 실선·필수 아이콘 | 진행 조건상 반드시 거쳐야 함. 근거 필요 |
| **추천역** | 본선 옆 짧은 경유선 | 초보자 실패·이동 시간을 유의미하게 줄일 근거가 있음 |
| **선택역** | 기본 숨김 | 엔딩에 필요 없고 시간상 이익이 미검증됨 |
| **복귀역** | 분기 후 합류 | 아이템·시대 전환 이후에만 접근 가능 |

사용자가 추천역을 생략해도 경로가 망가지지 않아야 하며, 선행 조건이 깨질 때 대안을 제공한다.

## 후보 루트 비교 절차

1. **판본 구분**: `oot-switch2-2026` 기준. 원작/N64/3DS와 다른 사실은 '버전 차이'로 분리.
2. **최종 목표 정의**: 일반적인 엔딩 도달. 100% 수집·버그 엔딩 제외.
3. **의존관계 나열**: 필수 아이템/노래/시대/이벤트 조건.
4. **후보 작성**: 최소 2개 자료를 기반으로 가능한 루트와 우회 경로를 나열.
5. **안정성 판단**: 일반 플레이어가 재현할 난이도, 재시도 시 손실, 장비 요구, 이동 낭비.
6. **비교·측정**: 직접 플레이 시 시간·실패·도움 요청을 구간별 기록.
7. **추천 결정**: '가장 빠름'을 주장할 수 없다면 '추천 동선'으로만 게시.
8. **재검증**: 리메이크 업데이트/유저 제보/새로운 증거 발견 시 갱신.

## 타협 기준

- 동선 최소화와 난이도 최소화가 충돌하면 **총 예상 소요시간 + 실패 위험**을 우선.
- 비교 지표가 부족하면 더 쉽고 정상적인 루트를 우선하되 '검증 중'으로 표시.
- 선택 장비는 획득 비용보다 이후 이득이 실측 또는 강한 근거로 예상될 때 포함.
- 아이템이 '좋다'는 이유만으로 포함 금지. 어떤 난관을 어떻게 줄이는지 설명해야 함.
- 퍼즐 정답 자동 노출은 시간 절약 지표에서 제외 (게임 재미를 훼손하므로).

## 검증 수준

- `proposed`: 기존 공략에서 제시된 후보, 자체 플레이 미확인
- `cross_checked`: 독립 출처 2개 이상 일치, 직접 플레이 미확인
- `playtested`: 실제 리메이크에서 재현 가능 확인
- `compared`: 두 루트 이상 조건을 맞춰 시간/실패를 비교, 기록 보존

`verified fastest` 같은 단계는 사용하지 않는다. 측정 가능한 주장만 한다.

## 장기 확장을 위한 철학만 기록

사용자의 《야숨》·《왕눈》 경험에서 얻은 일반 원칙: 이동 수단 확보, 쉽게 획득하는 성장 수단, 강한 장비/음식 준비, 최종 전투 전 보급 등은 **시간과 실패율을 줄일 때만** 추천한다. 두 게임의 구체적 동선은 이번 연구에서 작성하지 않는다.
