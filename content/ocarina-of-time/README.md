# 시간의 오카리나 콘텐츠

출발부터 엔딩까지 30개 구간, 31개 문제의 3단계 힌트, 21개 보유 조건을 앱에서 사용한다. 모두 **출처 기반 초안(proposed)** 이며 직접 플레이 미검증·공식 한글 용어 검수 대기다. 100% 수집·모든 방의 지도·최단 보장 공략은 아니다.

| 파일 | 책임 |
| --- | --- |
| [index.ts](index.ts) | 데이터 조합, 선택한 엔딩 노선의 선행 연결, 보유 조건 |
| [story.ts](story.ts) | 목표 요약, 상세 본문, 시대·준비 조건 |
| [puzzles.ts](puzzles.ts) | 관찰·구체적 단서·해법의 세 단계 |
| [sources.ts](sources.ts) | 열람한 출처 URL, 판본, 초안 검증 메타 |

필수(required)는 선택한 노선을 따라갈 때의 단계다. 유일하게 가능한 게임 순서나 모든 이동의 최적성을 뜻하지 않는다. 완료 체크가 아이템 획득·시대 전환을 자동으로 뜻하지 않는다.

작성 시 출처·판본·사실/추천 구분을 유지하고 자체 문장을 사용한다. 공식 표기를 확인하지 못했다면 caveat를 남긴다. 직접 플레이 증거 없이 상태를 승격하지 않는다. 상세 본문도 퍼즐 답을 포함하므로 요청한 뒤에만 DOM에 렌더링한다.

[집필·충돌 기록](../../docs/research/05-oot-story-draft.md) · [콘텐츠 모델](../../docs/architecture/02-content-model.md) · [실제 타입](../../src/lib/content.ts). `npm run check:content`는 ID·참조·문장·조건의 구조만 검사하며 게임 사실이나 최단성을 보증하지 않는다.
