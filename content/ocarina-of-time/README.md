# 시간의 오카리나 콘텐츠 영역

현재는 **실제 공략 데이터가 비어 있음**. 2026-11-08 문서 패키지는 개발 지침이며 게임 내 검증된 루트가 아니다. 이 파일은 그 사실을 명시하기 위한 것이며, 부정확한 '완성 공략' 대신 조사 결과를 점진적으로 넣는 장소다.

## 콘텐츠 입력 전 체크

1. 한국닌텐도 공식 이름을 확인했는가?
2. 리메이크 버전의 선행 조건을 확인했는가?
3. 후보 루트를 왜 추천하는지 `docs/game/01-route-criteria.md`에 근거가 있는가?
4. 기존 사이트·영상 내용은 자체 문장으로 새로 썼는가?
5. 직접 플레이 여부와 미검증 위험이 표시됐는가?
6. 퍼즐 정답은 단계별로 숨겨져 있는가?
7. 게임 스크린샷/영상 활용 권한이 있는가?

## 실제 데이터 파일 작성 방식

현재 진입점은 [`index.ts`](index.ts)이며 출처·조건·역·퍼즐 배열은 비어 있다. 검증한 사실만 해당 배열에 추가한다. 파일이 커지는 실제 필요가 생기면 `route/`, `puzzles/`, `sources/`로 나눈다. 가짜 최단 경로/임의의 UI 데모 역을 배포 데이터로 추가하지 않는다.

스키마·검증: [콘텐츠 모델](../../docs/architecture/02-content-model.md), [실제 타입](../../src/lib/content.ts). `npm run check:content`가 빌드 전에도 실행된다. 빈 배열 통과는 공략 사실 검증이나 제품 완성을 의미하지 않는다.

## 실제 콘텐츠 작성 템플릿

구간별 근거는 [`docs/research/03-route-decision-template.md`](../../docs/research/03-route-decision-template.md)에 기록한다. 통과한 역·퍼즐만 이 폴더에 추가하고, AI가 빈 역을 추측으로 자동 생성하지 않도록 한다.
