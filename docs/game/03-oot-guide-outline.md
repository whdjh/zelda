# 시간의 오카리나 전체 공략집 — 제작 범위와 집필 현황

> 현재 목표는 시작부터 엔딩까지의 전체 스토리·던전·보스·퍼즐 공략이다. 아래는 집필 누락을 막기 위한 내부 목차이며 검증된 최단 루트가 아니다. 100% 수집의 세부 범위는 별도 확정하고 로그인은 후순위로 둔다.

## 전체 구성

- **본문 공략**: 시작 조건, 이동/진입, 구간 진행, 퍼즐 도움, 중간/최종 전투, 완료 조건, 다음 구간과의 연결을 자체 문장으로 작성한다.
- **하이패스 보기**: 본문에서 현재 할 일을 최대 세 문장과 노선으로 요약한다. 전체 공략을 세 문장으로만 대체하지 않는다.
- **단계별 도움**: 관찰 → 구체적 단서 → 해법을 사용자가 요청할 때 공개한다. 보스와 이후 구간 이름도 스포일러 정책을 따른다.
- **장비·노래·조건 참조**: 언제 필요한지와 선행 조건을 본문에서 연결한다. 명칭과 판본 차이를 기록한다.
- **수집 확장**: 스토리 공략 이후 별도 범위/완료 기준을 확정한다. 첫 화면의 엔딩 노선과 분리한다.

## 전 구간 집필 작업표

아래는 [G01 스토리 목록](https://gamewith.jp/zelda-tokino-ocarina/563310)과 [C01 전체 안내](https://ootguide.com/ko/)를 범위 확인에 사용해 목표별로 묶은 편집 계획이다. C01은 GameWith 계열 자료를 정리하므로 독립 교차검증으로 세지 않았다. 원어 이름은 원자료의 식별자이며 공식 한국어 표기 확인 전 앱 제목으로 쓰지 않는다. 나열 순서만으로 실제 진행의 유일한 선후 관계를 단정하지 않는다.

| --- | --- | --- |

| 첫 던전 | Great Deku Tree 입장·진행·퍼즐·보스·완료 | 앱 본문·보스·힌트 작성 / 플레이 미확인 |

현재 앱에는 30개 역과 31개 문제(각 3단계 힌트)가 있다. [본문 데이터](../../content/ocarina-of-time/story.ts)와 [전 구간 기록](../research/05-oot-story-draft.md)을 함께 본다. 출처 기반의 압축된 스토리 초안이며 모든 방의 상세 지도나 100% 수집 공략은 아니다. [출처 등록부](../research/01-source-register.md), [첫 집필 초안](../research/04-oot-opening.md)도 보존한다.

## 첫 집필 단위의 완료 기준

첫 던전의 입장 전 준비부터 던전 완료까지 연결해 검수한다. 준비 구간만 작성했다고 첫 던전 공략 완료로 세지 않는다. 한 단위에서 아래 조건을 통과한 뒤 같은 방식으로 엔딩까지 확대한다.

1. 각 핵심 사실에 원출처·판본·검증 상태가 있다.
2. 입장/완료 조건과 보유/장착·시대 조건을 구분했다.
3. 본문·세 문장 요약·단계별 힌트가 자체 문장이다.
4. 실제 콘텐츠로 잠금·보유 조건 수정·진행 기록·힌트·스포일러를 검사했다.
5. 직접 플레이한 사실만 playtested로 올리고 남은 구간을 공개한다.

## 공략의 계층

- **Route**: 권장 엔딩 흐름을 따라가는 사용자용 노선.
- **Stop(역)**: 한 번에 이해할 수 있는 목표, 장소, 선행 조건, 완료 체크.
- **Problem(문제)**: 역 안에서 막힐 만한 퍼즐, 길 찾기, NPC, 전투.
- **Hint(힌트)**: 단서 1 → 구체화 2 → 해법 3. 기본 숨김.
- **Detour(추천 경유)**: 엔딩 시간 단축 또는 실패 위험 감소 근거가 있는 선택 준비.

## 조사 작업 패키지

| 패키지 | 확인할 것 | 승인 조건 |
| --- | --- | --- |
| 초반 진입 | 시작 지점, 필수 장비, 첫 던전 입장 조건 | 공식/2차 출처+리메이크 확인 |
| 초기 던전 | 진행 순서, 각 퍼즐 핵심, 보스 조건 | 모든 힌트 단계를 독립 검수 |
| 필드 이동 | 주요 지역 간 이동, 선행 이벤트/노래 | 게임 내 경로 재현 |
| 소년/청년 전환 | 접근 제약, 시대 전환 후 되돌아가기 | 분기/합류의 선행 조건 검증 |
| 중후반 신전 | 실제 필수 신전과 진행 제약 | 버전별 순서 가능 여부 확인 |
| 최종 준비·보스 | 추가 장비/보급의 실질적 가치 | 일반 실력 테스트 포함 |

원작 시오의 구조를 알고 있다는 이유만으로 '리메이크에서도 동일'이라고 단정하지 않는다. 한국닌텐도 공식 자료에는 소년/청년의 행동 차이와 오카리나 사용이 안내된다: https://www.nintendo.com/kr/games/switch2/aa9ja/dungeon/index.html

## 구간 완료 체크리스트

- [ ] 역 이름이 공식 한국어 이름과 일치한다.
- [ ] 입장/완료 조건이 객관적이고 모호하지 않다.
- [ ] 필수 아이템과 단순 권장 준비를 구분한다.
- [ ] 최단 동선의 이유 또는 미검증 상태를 기록했다.
- [ ] 3줄 요약만 보고 지금 무엇을 할지 파악할 수 있다.
- [ ] 힌트가 한 번에 정답을 노출하지 않는다.
- [ ] 되돌아갈 구간이 있다면 '왜 나중에'가 설명된다.
- [ ] 출처/버전/직접 플레이 검증 정보가 있다.

가짜 '완성 루트', 추측한 맵 좌표, 측정 없는 'n분 단축', 검증되지 않은 영상 타임스탬프, 유명 공략의 문장/이미지 복제.
