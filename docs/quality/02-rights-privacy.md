# 지식재산권·개인정보·서비스 고지

> 제품 기획을 위한 위험 관리 메모이며 법률 자문이 아님.

## 닌텐도 관련

- 대상 게임·세계관·시각 요소·상표는 닌텐도 권리와 연관될 수 있다.
- [한국어 닌텐도 네트워크 서비스 가이드라인](https://www.nintendo.co.jp/networkservice_guideline/ko/index.html)은 개인의 지정된 동영상/이미지 공유 사이트에서의 이용을 주로 설명한다. **독립 웹 공략 서비스와 배너 광고를 모두 허용하는 만능 라이선스가 아니다**.
- 게임 화면, 오디오, 컷신, 로고, 메달리온, 특유 문양·폰트는 게시 전에 권리 확인.
- 첫 버전은 자체 문장과 범용 선·역·상태 도형으로 개발. 실제 게임 화면 GIF/영상은 권한을 확보한 경우에만 게재.
- 서비스 하단에 '비공식 팬 프로젝트이며 Nintendo와 제휴·후원 관계가 없다'고 명시.
- 수익화(광고/유료) 전에 IP 검토를 별도 의사결정 게이트로 둔다.

## 외부 공략·유튜브

- 외부 사이트의 게임 사실을 조사해 자체 설명으로 작성할 수 있지만, **구체적 문장·지도·정리 배열·스크린샷을 상당 부분 복제하지 않는다**.
- 영상은 링크, 공개 제목, 확인한 시점, 관찰한 사실을 근거로 메모. `@nintaku_chick` 영상 자체를 다운로드하여 WebP 제작하지 않는다.
- 임베드/재사용은 YouTube 및 권리자 조건을 검토한 뒤 결정. 재업로드는 하지 않는다.
- 라이선스를 표시한 팬 UI 라이브러리도 해당 코드와 닌텐도 원저작물 권리를 구분한다.

## 오픈소스/폰트

- SEED 코드는 Apache-2.0; LICENSE/NOTICE 등의 의무를 준수. 당근 브랜드 리소스는 별도 제한: https://github.com/daangn/seed-design/blob/dev/NOTICE
- Pretendard는 SIL OFL 1.1을 적용한 폰트로 알려져 있으나 배포하는 파일/버전의 LICENSE를 함께 확인.
- 유튜브나 팬 라이브러리 포함 폰트가 자동으로 상업적 웹 배포를 허용한다고 가정하지 않는다.

## 개인 정보 및 기록

- 비로그인은 로컬에 완료역·보유 조건·힌트 공개·스포일러 설정을 저장한다. 후속 로그인을 연결하면 Supabase Auth가 이메일/인증 정보를 처리하고, 사용자가 서버 저장을 선택한 진행도는 본인 사용자 ID에 연결해 PostgreSQL에 보관한다. 이용 분석과 분리한다.
- GA4 등 제3자 분석 도구를 도입하면 쿠키/사용자 동의·고지 등 적용 법령을 별도 검토.
- 저장 정보는 기기/브라우저마다 다르며 비공개/캐시 삭제 시 소실 가능하다고 고지.
- 백업 JSON 파일에는 개인 식별 정보·위치·이메일·인증 토큰을 포함하지 않는다.
- 로그인 후 사용자가 직접 서버 저장/가져오기를 할 수 있다. 자동 동기화·기록 병합은 미구현이다. 공개 전 보유 기간/처리 위탁·국외 이전 해당 여부/계정 삭제 및 탈퇴 절차를 검토한다. 삭제 UI는 현재 미구현이며 운영 절차를 마련해야 한다.
- 로컬 데이터, 인증 쿠키, 서버 전송되는 진행 기록을 구분해 설명한다. 서비스 역할 키를 사용하지 않고 RLS로 본인 기록만 접근한다.
