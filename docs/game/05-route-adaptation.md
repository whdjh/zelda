# 시오 기본 노선과 진행도 기반 적응

## 목표

전체 노선을 탐색하고 목적지를 선택한다. 완료·보유 상태에 따라 남은 연결과 배치를 다시 구성한다. 기본 목적지는 엔딩이며 조건 기반 초안이다.

## 초기에 제공할 기능

- 역 완료·취소 / 현재 진행 지점 표시 / 필요한 아이템 보유 사실의 직접 수정.
- 선행 조건을 충족하는 다음 필수역 검색 및 추천 경유 재평가.
- 완료·보유 확인으로 불필요해진 경유선을 제거하고 분기·합류를 다시 배치.
- 선행 기록 누락으로 완료를 차단하거나 앞선 구간을 자동 완료하지 않는다.

## 추천 우선순위

1. 실제 엔딩의 **필수 조건** 충족 여부.
2. 사용자의 이미 완료/확인한 사실 유지.
3. 현재 상태에서 재현 가능한 정상 루트인지.
4. 일반 실력 플레이어의 이동·준비·실패 위험 절감 근거.
5. 근거가 동률이면 이동과 조작이 간단한 방향.

'한 번 완료한 역은 반드시 모든 선행 역을 완료했다고 간주'하지 않는다. 리메이크 구조와 노선 분기의 사실 관계를 먼저 조사한다.

## 노선 레이아웃

순수 규칙 함수가 위상 단계별 배치를 계산한다. SVG는 중복 선행 연결을 축약하고 실선(구간)과 점선(장비)을 구분한다. 교차는 환승역이 아니며 실제 점에서만 연결된다. 번호·상시 카드 없이 점을 누르면 설명을 연다. AI가 좌표를 생성하지 않는다.

## 추천 계산과 인증의 책임

규칙 계산 자체는 로그인 없이도 가능하다. 현재 기본 흐름은 로컬 진행도다. 서버 기록은 후속 후보이며 현재 준비 코드는 없다. 로그인 여부가 게임의 선행 조건을 바꾸지는 않는다.
