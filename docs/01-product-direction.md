# 제품 방향 — 증강 카드형 시오 내비

## 1. 핵심 경험

1. **갈래 선택 (증강 카드)**: 현재 위치에서 선택할 수 있는 다음 행동 2~3장을 스크롤 없는 한 화면에 제시합니다. (예: 메인 직행 / 안전 준비 / 이동 편의)
2. **짧은 진행 가이드**: 선택한 카드의 할 일을 최대 3줄로 보여주고, 더 보고 싶을 때만 단일 참고 사이트(**GameWith**) 링크를 엽니다.
3. **3단계 퍼즐 힌트**: 막혔을 때 정답을 바로 노출하지 않고 `관찰 → 단서 → 해법` 순으로 사용자가 연 만큼만 DOM에 렌더링합니다.
4. **함께 플레이하며 적립**: AI가 30개 구간을 미리 추측해 채우지 않고, 사용자가 직접 플레이하며 *"이 다음 어떻게 해?"*로 확인·검증한 갈래와 힌트만 앱에 추가합니다.

## 2. 공식 ZELDA NOTES와의 경계

| 영역 | ZELDA NOTES | 젤다 하이패스 |
| --- | --- | --- |
| 실시간 지도·위치·수집품 | 강점 (자동 연동) | **제외** (100% 수집 안 함) |
| 다음 갈래 의사결정 | 미제공 | **핵심** (증강 카드 2~3장 추천) |
| 스포일러 없는 퍼즐 힌트 | 미제공 | **핵심** (3단계 힌트) |
