# 조사·개발·검증·출시 실행 계획

> 초기 제품은 시오 엔딩까지 이어지는 **완성도 있는 첫 경험**을 목표로 한다. AI 코딩 생산성이 높아도 사실·권리·가독성 검증은 생략할 수 없다.

## 현재 우선순위

전체 스토리·던전·보스·퍼즐 공략의 출처 조사와 자체 문장 작성을 먼저 진행한다. 메인 한 화면과 핵심 기능만 유지한다. 로그인·서버 저장 준비 코드는 제거하고 도입 조건은 후속 후보 문서에 남긴다.

## 1. 설계 기준 고정 (완료)

- [x] 타깃/비목표, 추천 루트 기준, 퍼즐 힌트 원칙
- [x] SEED + Tailwind v4 + SEED 토큰, React 기본 상태 관리, localStorage 확정
- [x] 진행도 수동 수정 → 규칙 기반 경로 반영, 스포일러 기본 정책
- [x] 불필요한 추상화 금지, AI에게 가짜 공략 생성 금지
- [x] 초기 구현에서 SEED 3/API·Tailwind 레이어 적용과 기본 화면 빌드 확인 (전체 콘텐츠·시트의 접근성 검수는 별도)

## 2. 자료 조사 (게임 수령 전에도 가능)

- [ ] 한국닌텐도 공식 한글 명칭 목록 확보
- [ ] 기존 시오/리메이크 공략에서 **필수 조건/진입·완료 이벤트**를 사실 단위로 수집
- [ ] @nintaku_chick 관련 영상의 **실제** URL/타임스탬프/판본 기록
- [ ] 두 독립 출처 비교 및 충돌 기록
- [ ] 전체 엔딩 노선 후보, 필수역/추천 경유와 추천 근거 작성
- [ ] 3문장 행동 가이드와 단계별 퍼즐 힌트 초안 자체 작성

- [ ] localStorage 복구/버전/JSON 백업·복원, SSR hydration 확인
- [ ] 스포일러 strict/default/full과 퍼즐 별도 해금
- [ ] 한국어 SEO 진입 페이지 및 검색 결과 정답 누출 방지

## 후속 기능 (최초 출시에 포함하지 않음)
