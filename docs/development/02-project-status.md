# 현재 구현·검증 상태

> 2026-11-15(KST). 출처 기반 집필, 소프트웨어 검사, 실제 게임 검증을 구분한다.

## 현재 이용 가능

- 출발부터 엔딩까지 30개 역의 목표·상세 본문·준비 조건, 31개 문제의 93개 단계별 힌트, 21개 보유 조건. [집필 범위와 근거](../research/05-oot-story-draft.md).
- Next.js App Router/TS, SEED 3 + Tailwind 4 공식 토큰, 단일 메인·노선·역 Bottom Sheet 안의 퍼즐 도움·404·한국어 메타. 검증 전 noindex 유지.
- 목표 선택과 완료 허용을 분리했다. 준비물이 없어도 현재 목표를 볼 수 있으며, 완료 기록은 자유롭게 수정한다. 조건은 후보 안내와 연결 재계산에 사용한다.
- 상세 본문은 요청 후 렌더링한다. 힌트는 공개한 ID만 렌더링하며 기본은 전체 노선이며 점의 이름은 호버·길게 누르기·포커스로 연다. 각 공략과 문제에 출처·판본·초안 표시를 붙였다.
- localStorage 스키마 1, JSON 백업/교체 확인, UTF-8 크기·ID·버전 검사, 손상 원본 보존·다운로드, 저장 차단 고지. 시대 필드가 없는 기존 백업은 미확인으로 읽는다.
- 메인 / 하나만 제공한다. 네비바·사이드바·별도 역/퍼즐/로그인 페이지와 인증·서버 저장·SQL 준비 코드 및 전용 의존성은 제거했다. 이전 준비 코드는 Git 이력에서 참고한다.

## 메인 전용 정리 (2026-11-15)

- 메인 `/`에서 역 시트와 퍼즐 힌트를 열도록 통합했다. 힌트 공개 상태는 기존 localStorage 키/스키마로 복원하며 문제를 선택하기 전에는 DOM에 넣지 않는다.
- 메인의 사용법·중복 안내·준비 확인 수를 없애고 제목, 완료 수, 목적지와 남은 수, 조작 버튼만 남겼다. 초안·비공식·라이선스 고지는 하단 서비스 정보에 접어 두었다.
- 별도 브랜드 상단 바, `/oot` 계열·로그인·인증 콜백, 서버 Actions/proxy, Supabase 클라이언트/SQL/설정 문서와 전용 패키지를 제거했다. 후속 후보는 한 문서로 모았다. 기존 주소는 404이며 메인으로 돌아갈 수 있다.
- `npm run check`: 문서 36개·내부 링크 100개, 콘텐츠·린트·타입 검사와 단위 테스트 24개 통과. 최종 `npm run build`에는 `/`와 공통 404만 남는다.
- 프로덕션 서버의 Chrome 360/390px 검사: 완료 역 재열람 테스트의 목록 전환을 보완하고, 메인 문구 정리까지 반영한 최종 전체 26개가 모두 통과했다. 30역 본문·31문제/93힌트·저장 복구·키보드·정답 DOM 비노출·구주소 404·1280px 노선 배치를 포함한다. 모바일 캡처도 확인했다. 기존 개발 서버의 초기 로딩 실패와 샌드박스의 Chrome 시작 제한은 이 결과와 구분한다.
- 실제 휴대폰 제스처·스크린리더 수동 검수와 게임 직접 플레이는 미수행이다. 공략은 출처 기반 초안 상태를 유지한다.

## 이전 단일 화면·노선 배치 검증 (2026-11-12)

- 소개 페이지와 시작하기 단계를 제거했다. /oot에서 노선·진행도·설정을 바로 사용하고 /oot/route는 /oot로 이동한다. 역·퍼즐 고유 주소는 유지한다.
- 설정과 노선은 페이지의 useProgress 한 개를 props로 공유한다. 스포일러 설정, 완료 기록, 백업 복원을 새로고침 없이 함께 반영한다.
- 노선 배치는 연속 역의 세로축을 유지하고 긴 연결의 중간 공간을 예약한다. 수직선·45도 대각선과 짧은 둥근 모서리를 사용하며 SVG의 가로 늘어남을 제거했다.
- npm run check: 문서 38개·내부 링크 112개, 콘텐츠, 린트, 타입 검사와 단위 테스트 24개 통과. npm run build 통과.
- 실제 Chrome Playwright: 기존 localhost:3000 서버에서 360/390px 총 26개 통과. 설정·백업·저장 실패, 단일 화면 상태 공유, 모든 역·힌트, 목적지·장비 변경, 키보드·터치 이벤트, 스포일러 DOM 검사를 포함한다. 노선은 1280px도 확인했고 다른 역 관통·가로 늘어남이 없었다. 마지막 역 이름의 잘림 방지 보완 후 관련 검사 2개도 재통과했다.
- 모바일 화면과 노선 캡처를 확인했다. 실기기 제스처·스크린리더 수동 검수와 게임 플레이 검증은 별도로 남아 있다.

## 이전 선형 UI의 검증 기록 (2026-11-08~09)

- `npm run check`: 문서 37개·내부 파일 링크 106개, 콘텐츠 참조, 린트, 타입 검사와 단위 테스트 17개 통과. 외부 URL·문서 내 앵커는 자동 링크 검사에서 제외한다.
- `npm run build`: Supabase 환경변수 없이 프로덕션 빌드 통과. 홈·노선 정적 렌더와 개별 역/문제 경로를 생성했다.
- 실제 데이터 테스트: 첫 역부터 마지막 역까지 모든 목표를 순회하고 준비물·시대를 명시적으로 확인한 경우 완료 가능함을 검사했다. 완료가 시대·장비를 자동 획득시키지 않으며 시대 전환이 과거 완료와 충돌하지 않음을 검사했다.
- Playwright: 기존 개발 서버를 쓰는 임시 설정으로 12개(6개 시나리오 × 360/390px)를 시도했으나 Chrome 프로세스가 sandbox에서 SIGABRT/kill EPERM으로 시작하지 못했다. 테스트 본문 실행 전 실패이며 전체 통과로 보고하지 않는다. 기본 설정의 별도 서버 실행도 이전에 listen EPERM으로 막혔다.
- 실제 Chrome(agent-browser): 360/390px 노선·역 시트에서 가로 넘침 없음. 미래 마지막 역 이름과 상세 본문은 기본 DOM에 없고 상세 버튼 뒤 본문이 나타났다. 시대 미확인 시 완료 차단, 소년 확인 뒤 완료 가능, 완료 뒤 다음 목표 선택, 준비물 미확인 차단·보유 확인 뒤 허용과 실제 저장 값을 확인했다. 퍼즐은 초기 힌트 0개·정답 없음, 1단계 뒤 1개·정답 없음, 정답 요청과 새로고침 뒤 해법 유지로 확인했다. Playwright 전체 통과나 실기기/스크린리더 검증으로 간주하지 않는다.
- 전수 표시 검사: 전체 공개 모드에서 360px와 390px 각각 30개 역의 시트를 모두 열었다. 요청 전 상세 본문 미존재, 요청 뒤 전체 123문단의 텍스트 지문 일치, 31개 문제로 향하는 링크·구간별 출처 링크, 가로 넘침 없음을 확인했다.
- 전수 힌트 검사: 두 화면 폭 각각 31개 문제 페이지를 모두 방문했다. 초기 0개, 1→2→해법 순서로 공개, 93개 힌트의 텍스트 지문 일치, 새로고침 뒤 3단계 복원, 가로 넘침 없음을 확인했다. 이 검사는 별도 브라우저에서 실제 클릭과 DOM 검사로 수행했으며 Playwright runner 결과와 구분한다.
- 개별 주소 검사: 30개 역 URL과 31개 문제 URL 모두 HTTP 200, 존재하지 않는 역/문제 URL은 각각 404였다.
- 전수 본문·힌트 시나리오를 Playwright에도 추가했다. 현재 8개 시나리오 × 2개 화면 폭이다. 전체 runner는 위 Chrome 시작 제한 때문에 미통과이며, 브라우저 전수 검사를 runner 통과로 기록하지 않는다.
- `npm run test:e2e -- --list`: 16개 테스트 수집 통과. 브라우저를 실행하는 검증은 아니다.
- 게임 직접 플레이·공식 한글 명칭·모든 방의 경로 재현·최적성·실측 시간: 미수행. 전 구간은 proposed로 유지한다.

## 기존 기반 검증 기록

- 콘텐츠 입력 전 Chrome 360/390px에서 홈·설정 가로 넘침, 저장/새로고침 복원, 잘못된 JSON 거부·기록 유지, 정상 백업 교체·내보내기, 손상 원문 보존·다운로드를 확인했다. Enter/Escape와 포커스 복귀를 확인했다.
- 기존 홈 axe 4.12.1 대비 위반 6곳을 SEED contrast 토큰으로 고친 뒤 0건이었다. 이번 공략 본문까지 자동 접근성 통과한 것으로 확대 해석하지 않는다. 실기기·스크린리더 수동 검수가 남아 있다.
- 의존성 설치 중 moderate 경고 8건. 상세 npm audit 요청은 registry DNS 오류로 완료하지 못했다. 공개 전 상세 확인·호환 패치를 검토한다.
- 임시 PGlite 메모리 PostgreSQL에서 실제 SQL 마이그레이션과 RLS 회귀 시나리오를 통과했다. 본인/타인/anon 권한, revision 경쟁 갱신과 rollback을 검사했다. Supabase Auth 실제 서비스 통합은 미수행이다.
