# 엔딩 경로 연결과 준비물 재검토

조사일: 2026-11-16. 판본: `oot-switch2-2026`. 대상은 속도가 아니라 **안내 순서의 진행 가능성과 빠진 준비물**이다. [이전 조사](07-route-speed-audit.md)의 장별 연결 검토에 이어 본문과 준비물 검사 사이의 불일치를 조사했다.

## 판정 범위

기본 경로의 소년 3던전 → 시간의 신전 → 청년 숲·불·얼음·물 → 소년 우물 → 청년 어둠·사막 → 소년 혼 → 청년 혼·최종 성 연결은 장별 자료와 대응한다. 그러나 세부 안내에는 실제 누락이 있었으며 아래와 같이 수정했다. 따라서 수정 전 본문을 오류 없는 공략으로 보증하지 않는다.

출처 대조와 앱의 조건 검사는 실제 게임의 모든 방을 통과했다는 증거가 아니다. 전체 31문제의 해법, 소모품 잔량, 플레이 중 실수에서의 복구를 이번 작업으로 전수 검증하지 않았다. 직접 플레이 기록이 없으므로 모든 콘텐츠의 `proposed` 상태를 유지한다. 참고 링크는 GameWith 한 사이트를 유지하며 별도의 실제 조사 출처는 삭제하지 않는다.

## 발견과 수정

| 구간 | 발견한 문제와 수정 | 근거 |
| --- | --- | --- |
| 숲 지하 회전방 | 첫 스위치를 생략했던 안내에 회전·점화·눈 스위치 순서를 추가 | [숲의 신전](https://gamewith.jp/zelda-tokino-ocarina/563391) |
| 물 후반 | 롱샷 이후 구판 시간 블록 설명을 현 판본 이동으로 교체. 보스 열쇠의 해머 경로를 명시하고 준비 조건에 반영. 허수아비 없이 서쪽으로 올라가는 경로 사용 | [물의 신전](https://gamewith.jp/zelda-tokino-ocarina/563388) |
| 물·우물 | 본문에서 사용하는 자장가, 물 구간의 폭탄을 준비물 검사에도 추가 | [물](https://gamewith.jp/zelda-tokino-ocarina/563388), [우물](https://gamewith.jp/zelda-tokino-ocarina/563387) |
| 어둠 | 훅샷, 헤비 부츠, 자장가, 딘의 불꽃, 폭탄 준비 검사 보강. 숨은 방 열쇠 안내 추가 | [어둠의 신전](https://gamewith.jp/zelda-tokino-ocarina/563386) |
| 혼 소년·청년 | 눈 스위치용 새총과 폭탄쥐 상자 획득 순서 추가. 청년 훅샷·자장가 조건 보강. 어둠보다 혼을 먼저 마쳤다면 남은 어둠 이후 시간의 신전으로 가도록 안내 | [혼의 신전](https://gamewith.jp/zelda-tokino-ocarina/563384) |
| 최종 성 | 본문에 쓰는 롱샷·자장가·마법·폭탄·활 준비 검사 보강. 빛의 화살 수령 확인, 소모품 보충과 폭탄쥐 보충처 추가 | [최종 성](https://gamewith.jp/zelda-tokino-ocarina/563383), [폭탄쥐](https://gamewith.jp/zelda-tokino-ocarina/587589) |

준비 조건은 이번에 채택한 상세 경로의 조건이다. 예를 들어 물 후반의 해머 조건은 참고 경로를 안전하게 따르기 위한 것으로, 다른 모든 공략에서도 해머가 반드시 필요하다는 판정이 아니다. 물 초반 진입과 불 보스 완료를 강제로 묶지는 않는다.

## 소프트웨어 검증의 의미

- 빈 소년 기록에서 시작해 추천 구간을 완료하고 **그 구간의 획득물만 사용자가 확인하는 상황**을 재현한다. 이후 구간에 필요한 장비를 테스트가 미리 지급하지 않는다. 숲 완료 뒤 시대 복귀와 엔딩 도달을 검사한다.
- 이미 구간 완료 기록이 있어도 준비물 확인을 취소하면 준비된 후보로 표시하지 않는지 검사한다.
- 이러한 테스트는 데이터가 표현한 조건 안에서의 연결만 확인한다. 출처 자체의 오류, 아직 모델에 없는 조건, 실제 게임 조작 성공까지 증명하지 않는다.

최종 실행 결과는 [현재 검증 상태](../development/02-project-status.md)에 기록한다. 남은 실제 검수는 앱 본문으로 플레이하며 막힌 방·직전 행동·현재 장비·시대를 기록하고, 해당 구간의 출처와 대조해 보강하는 것이다.
