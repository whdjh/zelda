# 현재 구현·검증 상태

> 2026-11-08. 프로젝트 초기 기반과 제품 출시 완료를 구분한다.

## 현재 우선순위

ADR-013에 따라 전체 공략집 조사·작성과 비로그인 이용이 우선이다. 준비한 로그인/서버 코드는 보존하되 기본 홈에서 연결을 보류했다. Supabase 프로젝트나 키는 지금 필요하지 않다.

## 준비한 기반

- Next.js App Router/TS, SEED 3 + Tailwind 4 공식 토큰과 레이어 설정.
- 모바일 홈과 준비 중 안내, 노선/역/퍼즐 URL, 없는 콘텐츠 404, 한국어 메타/초기 noindex.
- RouteMap/RouteGuide, 역 Bottom Sheet, 단계별 HintReveal. 실제 게임 데이터는 비어 있으며 테스트 전용 데이터만 별도로 사용한다.
- 규칙 기반 후보 계산·조건 충돌/공개 범위 함수. 복잡한 시대/이벤트와 경유 비용 모델은 실제 조사 후 확장한다.
- 브라우저 진행 스키마 1, JSON 백업/복원 확인, 크기·ID·버전 검사, 손상 원본 다운로드와 저장 차단 안내.
- 후속 연결용 이메일 링크 요청/콜백/로그아웃, Supabase 쿠키 클라이언트와 proxy, 사용자별 서버 읽기/저장 Action.
- PostgreSQL 사용자 진행 스냅샷, RLS, revision 경쟁 수정 검사, 격리 DB용 SQL 회귀 시나리오.
- 보존된 서버 기록 코드는 명시적 저장/가져오기이며 로그인만으로 로컬/서버 기록을 자동 교체하지 않는다.

## 검증 기록

최종 작업 결과를 아래에 기록한다. 소스 작성과 실제 외부 통합 검증을 동일하게 취급하지 않는다.

- `npm run check`: 통과. Markdown 36개·내부 파일 링크 93개, 콘텐츠 검사, ESLint, 타입 검사, Node 단위 테스트 14개. 외부 URL과 문서 내 앵커는 링크 검사 범위에서 제외한다.
- `npm run build`: 최종 코드에서 Supabase 환경변수 없이 프로덕션 빌드 통과. 공략 우선 변경으로 /oot는 인증 조회 없이 정적 렌더하며 /login은 후속 준비 경로로 유지한다.
- 실제 Chrome 브라우저: 360/390px에서 홈·설정 가로 넘침 없음, 설정 저장/새로고침 복원, 잘못된 JSON 거부·기존 상태 유지, 정상 백업 교체, 내보낸 파일의 스키마, 손상 원문의 보존/다운로드, 로그인 미설정 안내와 빈 노선/없는 ID 안내를 확인했다. 키보드 Enter로 시트 열기·Escape로 닫기·트리거 포커스 복귀를 확인했으며 브라우저 오류 목록은 비어 있었다.
- 로그인 후순위 변경 후 360px 브라우저에서 기본 설정에 스포일러·백업만 표시되고 로그인/서버 기록 영역은 DOM에 나타나지 않는 것을 추가 확인했다.
- axe 4.12.1 홈 검사: 대비 부족 6곳을 SEED contrast 토큰으로 고친 뒤 위반 0건. 시트는 라이브러리 pseudo-element 배경과 focus trap 때문에 자동 판정 불가 항목이 있어 스크린리더/수동 검수가 남아 있다.
- `npm run test:e2e`: 실행 시 테스트 서버 listen EPERM로 중단. 같은 시나리오 일부를 agent-browser로 별도 확인했으며 Playwright 전체 통과로 보고하지 않는다. 로컬 제한 없는 환경에서 다시 실행할 수 있도록 360/390px용 시나리오 5개를 작성했다.
- 의존성: 설치 중 moderate 경고 8건이 보고되었다. `npm audit` 상세 요청은 registry DNS 오류(ENOTFOUND)로 완료하지 못했다. offline audit의 0건을 정상 보안 검사로 간주하지 않는다. ESLint 9는 Next 플러그인 호환성 때문에 유지하며 폐기 예정 경고도 남아 있다. 공개 전 네트워크 가능한 환경에서 상세 확인·호환 패치를 검토해야 한다.
- 원격 인증/DB: 미수행. Supabase 프로젝트/키가 없고 로컬 Docker daemon도 실행 중이 아니다.
- SQL 독립 검증: 임시 설치한 PGlite 0.5.15의 메모리 PostgreSQL에서 실제 마이그레이션과 supabase/tests/user_progress.sql을 실행해 통과했다. 본인 읽기/쓰기, 타인 읽기·삽입·수정·삭제 차단, anon 차단, revision 증가·낡은 갱신 거부, 소유자 변경 거부, JSON null 스키마 거부, 최종 rollback을 확인했다. auth.users/auth.uid 및 역할은 테스트용으로 준비했으므로 Supabase 인증 서비스 통합 검증을 대신하지 않는다. 앱 의존성에는 추가하지 않았다.
- 게임 플레이/실제 명칭·경로·힌트: 미수행, 공략 데이터 0개.
- 실기기·스크린리더·색 대비·긴 콘텐츠/복잡 분기: 별도 검증 필요.

## 전체 공략집 집필 현황

- [전체 구성](../game/03-oot-guide-outline.md): 출발 준비부터 엔딩까지를 여덟 집필 묶음으로 정리했다. 외부 목차의 범위 대조이며 각 구간의 본문/동선 검증 완료를 뜻하지 않는다.
- [초반 장비 초안](../research/04-oot-opening.md): Switch 2판을 명시한 세 편집처의 관련 본문에서 여섯 사실을 비교하고, 자체 본문·행동 요약·단계별 도움을 작성했다. 한글 표기와 직접 플레이가 남아 전체 상태는 proposed다.
- OoT Guide가 GameWith/Nintendúo 자료를 정리한다고 밝힌 계보를 등록했다. 같은 원출처의 재정리를 독립 근거 두 개로 세지 않는다.
- 앱 게시 역/퍼즐은 여전히 0개다. 첫 던전의 입장부터 완료까지 연결하고 실제 조건/UI 검사를 거친 뒤 앱 데이터로 옮긴다.

## 입력 문서 정리

작업 디렉터리에 ZIP 파일이 없어 이미 압축 해제된 기존 Markdown을 입력으로 사용했다. 기존 분야별 디렉터리와 조사 기록은 유지했다. 실행·설정 문서는 development에 모으고 README/START-HERE/색인의 역할을 분리했으며, 서버 제외 결정은 폐기 이력을 남긴 뒤 현재 설계로 교체했다.
