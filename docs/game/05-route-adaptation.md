# 시오 기본 노선과 진행도 기반 적응

## 목표

게임 시작 전 **하나의 추천 기본 루트**를 구성한다. 사용자에게 여러 경로를 매번 선택하게 요구하지 않는다. 사용자가 이미 다른 구간을 진행했거나 조건을 갖춘 경우에는 **남은 추천 경로와 경유 우선순위**를 다시 제안한다.

## 초기에 제공할 기능

- 역 완료·취소 / 현재 진행 지점 표시 / 필요한 아이템 보유 사실의 직접 수정.
- 선행 조건을 충족하는 다음 필수역 검색 및 추천 경유 재평가.
- 변경 결과를 기존 세로 노선도의 '현재'·'완료'·'잠금'·'추천' 상태로 반영.
- 모순되는 진행 기록에 대해 **사용자에게 확인** 요청, 게임 상황을 AI가 임의 추정하지 않는다.

## 추천 우선순위

1. 실제 엔딩의 **필수 조건** 충족 여부.
2. 사용자의 이미 완료/확인한 사실 유지.
3. 현재 상태에서 재현 가능한 정상 루트인지.
4. 일반 실력 플레이어의 이동·준비·실패 위험 절감 근거.
5. 근거가 동률이면 이동과 조작이 간단한 방향.

'한 번 완료한 역은 반드시 모든 선행 역을 완료했다고 간주'하지 않는다. 리메이크 구조와 노선 분기의 사실 관계를 먼저 조사한다.

## 노선 레이아웃

초기에는 UI 좌표/큰 노선 구조를 안정적으로 유지한다. 사용자 경험 개선이 실제 확인되면 새로운 경로를 부드럽게 재배치하는 기능을 추가할 수 있지만 **AI 생성 레이아웃은 후속 별도 기능**이다.

## 추천 계산과 인증의 책임

규칙 계산 자체는 로그인 없이도 가능하다. 현재는 Supabase Auth로 서버 기록의 소유자를 확인하고 PostgreSQL에 사용자별 상태를 보관한다. 같은 순수 규칙 함수를 UI와 Server Action에서 재사용하며, 로그인 여부가 게임의 선행 조건을 바꾸지는 않는다.
