# 타깃·포지셔닝·사용자 여정

## 메인 타깃 — '효율적 첫 엔딩' 사용자

- 시오를 처음 플레이한다.
- 프레임 단위 조작이나 스피드런 기술을 요구받기 싫다.
- 퍼즐은 가능하면 스스로 풀되, 막혀서 30분을 날리는 일은 피하고 싶다.
- 모든 수집품은 필요 없지만, 특정 준비가 보스 도전을 크게 쉽게 만든다면 들르고 싶다.
- 게임을 끄고 공략을 계속 읽는 방식보다 폰에서 몇 초간 확인하는 방식을 선호한다.

이는 **행동 기반 페르소나 가설**이지 현재 리서치에서 측정한 실제 사용자 비율이 아니다.

## 사용자 세분화

| 구분 | 핵심 니즈 | 제공 가치 |
| --- | --- | --- |
| 야숨/왕눈 출신 첫 시오 | 퍼즐/선형 구조 적응 | 목적지 + 요청형 힌트 |
| 젤다 시리즈 첫 유저 | 막히지 않는 진행 | 필수/추천 준비 설명 |
| 시간 제한 있는 일반 게이머 | 짧은 세션 효율 | 현재 해야 할 일 3줄 |
| 수집 완주형 | 수집 목록·지도 | 후속 100% 모드, 초기 제품 중심에서 제외 |

## 사용자의 대안

1. 게임 내 목적지 안내 (`Threads of Time`, `ZELDA NOTES`).
2. 전체 공략/위키 (Zelda Dungeon, OoT Guide).
3. 영상 공략 (유튜브 크리에이터, 예: 사용자가 추천한 `@nintaku_chick` — 개별 영상 조사 전).
4. 생성형 AI에 공략을 넣고 질문하기 (사용자의 야숨·왕눈 경험에서 얻은 착안점).

## 차별성 약속의 상한

- '글리치 없는 최적 경로를 전적으로 증명'은 아직 불가.
- 출시 문구는 '일반 플레이어를 위한 추천 엔딩 루트'를 기본으로 한다.
- 기준·비교 기록이 충분히 쌓인 구간에서만 정량적 개선 주장을 한다.

## 사용자 여정

검색 → 정확한 구간 진입 → 현재 역 확인 → 3줄 행동 파악 → 선택적 힌트 → 완료 표시 → 다음 세션 복원 → 엔딩.

모든 화면은 이 여정 중 어떤 문제를 해결하는지 설명할 수 있어야 한다.
