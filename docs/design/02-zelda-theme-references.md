## 왜 젤다 팬 UI 라이브러리를 직접 쓰지 않는가?

- 제공된 디자인이 주로 **야숨의 시커 스톤**을 닮아, 시오 중심 제품의 분위기와 다르다.
- 팬 제작 저장소의 코드 MIT와 **닌텐도 IP/2차 저작물 사용 권한은 별개**다.
- 팬 아트·아이콘·음악·로고의 저작권, 폰트 재배포 허가는 별도로 판단해야 한다.
- 모바일 노선도 본연의 사용성을 해치는 과도한 장식은 우선순위에서 밀린다.

## 제안하는 독자 테마

- **주요 형태:** 노선(선), 역(원), 경유/환승(갈림길), 완료/현재/미진행 상태.
- **분위기:** 짙은 숲과 오래된 지도에서 영감 받은 추상적 톤. 눈금·윤곽·절제된 금색 포인트.
- **금지:** 닌텐도 로고와 트라이포스·시커 문양·기존 게임 UI를 거의 동일하게 재현, Nintendo 공식 서비스처럼 보이는 UI.
- **선호:** 자체 제작 원/선/방패형 범용 도형, 라이선스 확인된 Lucide 등 범용 아이콘, 읽기 쉬운 한글.

## 디자이너 이론 적용 체크

- [ ] 컬러가 감정/의미와 함께 접근성 기준을 만족하는가?
- [ ] 텍스트 위계가 3초 훑어보기에서 드러나는가?
- [ ] 노선의 형태가 위치·완료·추천의 관계를 설명하는가?
- [ ] SEED 기본 컴포넌트 스타일과 테마가 충돌하지 않는가?
- [ ] 다른 젤다 작품을 추가해도 현재 시오의 고유한 경험이 유지되는가?

## 법률 및 권리 보류

비공식 팬 프로젝트이며 닌텐도와 제휴·후원 관계가 아님을 명시한다. [한국어 닌텐도 가이드라인](https://www.nintendo.co.jp/networkservice_guideline/ko/index.html)은 기본적으로 **지정된 동영상·이미지 공유 사이트** 대상이므로 독립 공략 웹사이트/광고 수익/게임 영상 재호스팅에 포괄적 허용으로 해석하지 않는다.
